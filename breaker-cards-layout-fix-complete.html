四个状态卡片现在在同一行显示，布局更加紧凑美观

问题分析

在断路器监控页面中，四个状态卡片的布局存在以下问题：

  • 卡片过宽：每个卡片占用空间过大，导致无法在同一行显示
  • 自适应布局：使用了 auto-fit 和 minmax(280px, 1fr)，在空间不足时会换行
  • 间距过大：卡片内边距和图标尺寸过大，浪费空间
  • 文字溢出：长文本没有处理溢出，可能导致布局问题

解决方案

🔧 核心修改

1. 修改网格布局

❌ 修改前

.status-cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 20px; }

✅ 修改后

.status-cards { display: grid; grid-template-columns: repeat(4, 1fr); gap: 16px; }

2. 优化卡片样式

.status-card { background: white; border-radius: 12px; padding: 16px; /* 从20px减少到16px */ box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1); border-left: 4px solid #52c41a; transition: all 0.3s ease; min-width: 0; /* 新增：允许卡片收缩 */ }

3. 调整图标和文字大小

.status-icon { width: 48px; /* 从60px减少到48px */ height: 48px; /* 从60px减少到48px */ font-size: 24px; /* 从32px减少到24px */ margin-right: 12px; /* 从16px减少到12px */ flex-shrink: 0; /* 新增：防止图标被压缩 */ } .status-info h3 { font-size: 14px; /* 从16px减少到14px */ white-space: nowrap; /* 新增：防止换行 */ overflow: hidden; /* 新增：隐藏溢出 */ text-overflow: ellipsis; /* 新增：显示省略号 */ } .status-value { font-size: 18px; /* 从20px减少到18px */ } .status-subtitle { font-size: 12px; /* 从14px减少到12px */ white-space: nowrap; /* 新增：防止换行 */ overflow: hidden; /* 新增：隐藏溢出 */ text-overflow: ellipsis; /* 新增：显示省略号 */ }

修复效果

✅ 修复完成！ 四个断路器状态卡片现在可以在同一行显示，布局更加紧凑美观。
