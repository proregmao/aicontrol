错误触发机制

// 后端验证逻辑 (temperature_controller.go:834) if id == 0 { ctx.JSON(http.StatusBadRequest, models.APIResponse{ Code: http.StatusBadRequest, Message: "缺少告警规则ID", }) return }

探头1特殊性：作为数组第一个元素，索引为0，触发了后端的ID验证失败。

3. 提交时使用真实ID
