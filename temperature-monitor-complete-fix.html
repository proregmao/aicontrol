🎯 使用指南

操作步骤

1. 设置新告警规则：

访问 /temperature/monitor 页面 → 点击"设置告警"按钮 → 填写表单信息 → 点击"保存"


2. 编辑现有告警规则：

在告警阈值设置表格中 → 点击对应行的"编辑"按钮 → 修改参数 → 点击"更新"


3. 删除告警规则：

在告警阈值设置表格中 → 点击对应行的"删除"按钮 → 确认删除


4. 表单字段说明：

• 探头：选择要设置告警的温度探头

• 位置：描述探头的安装位置

• 正常范围：设置正常工作温度范围

• 警告阈值：设置警告温度范围

• 危险阈值：设置危险温度阈值

• 启用告警：开启或关闭该告警规则
