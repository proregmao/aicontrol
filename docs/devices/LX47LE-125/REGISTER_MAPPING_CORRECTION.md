# LX47LE-125 寄存器映射修正文档

> **修正时间**: 2025年9月25日  
> **修正原因**: 通过实际测试发现寄存器映射错误  
> **测试验证**: 已通过实际设备测试验证  
> **影响范围**: 电压和电流读取算法

## 🚨 关键问题发现

### 问题描述
在实际测试中发现，我们的寄存器映射存在严重错误，导致：
- **电压读取为0V** (实际应该读取到220V+)
- **电流读取异常** (读取到了电压寄存器的值)
- **数据解析错误** (电压和电流寄存器地址冲突)

### 根本原因
**寄存器地址映射错误**：将30008同时映射给了温度和电压寄存器。

## ✅ 修正后的正确映射

### 单相断路器寄存器映射 (已验证)
```go
// 温度寄存器
REG_TEMP_N           = 0x0006 // 30007: N线温度
REG_TEMP_A           = 0x0007 // 30008: A相温度

// 电气参数寄存器 (修正后)
REG_VOLTAGE_A        = 0x0008 // 30009: A相电压 ✅ 修正
REG_CURRENT_A        = 0x0009 // 30010: A相电流 ✅ 修正
REG_POWER_FACTOR_A   = 0x000A // 30011: A相功率因数
REG_ACTIVE_POWER_A   = 0x000B // 30012: A相有功功率
REG_REACTIVE_POWER_A = 0x000C // 30013: A相无功功率
```

### 错误映射 vs 正确映射对比
| 寄存器 | 错误映射 | 正确映射 | 测试结果 |
|--------|----------|----------|----------|
| 30007 | N线温度 | N线温度 | ✅ 24°C |
| 30008 | **温度+电压冲突** | A相温度 | ✅ -40°C |
| 30009 | A相电流 | **A相电压** | ✅ 225V |
| 30010 | - | **A相电流** | ✅ 0.00A |
| 30011 | A相功率因数 | A相功率因数 | ✅ 0.00 |

## 🔧 算法修正

### 数据转换算法 (保持不变)
```go
// 电压读取 (直接使用原始值)
voltage := float64(rawVoltage) // 单位: V

// 电流读取 (除以100转换)

// 温度读取 (减去40偏移)

```

### 寄存器读取顺序
```go
// 正确的读取顺序
func ReadElectricalParameters(breaker *models.Breaker) error {
    // 1. 读取A相电压 (30009)
    voltage, err := ReadInputRegister(breaker, 30009)
    
    // 2. 读取A相电流 (30010)  
    current, err := ReadInputRegister(breaker, 30010)
    
    // 3. 读取A相功率因数 (30011)
    powerFactor, err := ReadInputRegister(breaker, 30011)
    
    return nil
}
```
