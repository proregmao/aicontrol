📧 告警模板管理功能

智能设备管理系统 - 多模式告警通知解决方案

🎯 功能概述

📧 邮件通知模板

支持SMTP邮件服务器配置，可自定义邮件模板内容，支持多收件人、抄送、密送功能。

  • SMTP服务器配置
  • 自定义邮件模板
  • 多收件人支持
  • 邮件内容模板化

💻 界面提示模板

浏览器内弹窗告警，支持Toast提示、模态框、徽章提示等多种展示方式。

  • 多种提示类型
  • 自定义显示位置
  • 声音提醒功能
  • 自动消失时间

📱 钉钉通知模板

集成钉钉群机器人，支持Markdown格式消息，可@指定人员或全体成员。

  • 钉钉群机器人
  • Markdown格式
  • @人员功能
  • 安全签名验证

🔧 模板类型配置

📧

邮件通知配置

完整的SMTP邮件服务器配置，支持SSL/TLS加密连接

  • SMTP服务器地址
  • 端口号（默认587）
  • 发送邮箱账号
  • 邮箱授权密码
  • 收件人列表
  • 邮件主题模板
  • 邮件内容模板
💻

界面提示配置

灵活的浏览器内通知配置，支持多种展示效果

  • 通知类型（Toast/Modal/Badge）
  • 显示位置（四个角落）
  • 显示时长（1-30秒）
  • 声音提醒开关
  • 图标映射配置
  • 颜色主题配置
📱

钉钉通知配置

企业级钉钉群通知，支持富文本和@功能

  • Webhook URL
  • 安全密钥（可选）
  • @手机号列表
  • @所有人开关
  • 消息类型（Text/Markdown）
  • 消息内容模板

🔌 API接口文档

GET /api/v1/alarms/templates
获取告警模板列表，支持按类型筛选
POST /api/v1/alarms/templates
创建新的告警模板
PUT /api/v1/alarms/templates/{id}
更新指定的告警模板
DELETE /api/v1/alarms/templates/{id}
删除指定的告警模板
POST /api/v1/alarms/templates/{id}/test
测试指定的告警模板
