📋 测试说明

  • 问题描述：删除确认弹窗显示在页面顶部，而不是居中显示
  • 修复方案：将原生 confirm() 替换为 Element Plus 的 ElMessageBox.confirm() 并启用居中显示
  • 测试方法：点击下方按钮访问告警管理页面，尝试删除告警规则，观察弹窗位置
  • 预期结果：删除确认弹窗应该在浏览器窗口正中央显示

🔧 修复内容

将删除确认弹窗从原生 confirm() 方法替换为 Element Plus 的 ElMessageBox.confirm() 方法，并添加 center: true 属性启用居中显示。
