智能告警系统通知方式配置说明

了解如何配置和管理告警通知方式

📍通知方式配置位置

通知方式是在告警规则中配置的，不是独立的配置项。

📝配置步骤

  1. 进入告警管理页面
    访问智能告警模块，查看告警规则配置区域
  2. 新增或编辑告警规则
    点击"新增规则"按钮创建新规则，或点击现有规则的"编辑"按钮
  3. 配置基本信息
    填写规则名称、告警类型、触发条件、告警等级等基本信息
  4. 选择通知方式
    在"通知方式"部分，勾选需要的通知渠道（支持多选）
  5. 保存规则
    点击"保存"按钮，通知方式配置即生效

📱支持的通知方式

💻
界面提示
在系统界面显示告警通知
📧
邮件通知
发送告警邮件到指定邮箱
📱
短信通知
发送告警短信到指定手机
📲
钉钉通知
发送告警消息到钉钉群

🔗关联关系

一对一关系

每个告警规则都有自己独立的通知方式配置：

  • 告警规则A → 钉钉通知
  • 告警规则B → 邮件 + 短信通知
  • 告警规则C → 界面提示 + 钉钉通知

统计卡片显示逻辑

统计卡片中的"通知方式"状态是基于所有告警规则的通知方式配置计算的：

✅
已配置

⚠️
未配置
所有告警规则都没有配置通知方式

💡使用建议

通知方式选择建议

  • 严重告警：建议配置多种通知方式（钉钉 + 短信 + 邮件）
  • 警告告警：建议配置钉钉或邮件通知
  • 信息告警：建议配置界面提示即可

最佳实践

  • 为不同等级的告警配置不同的通知方式
  • 重要告警建议配置多种通知渠道，确保及时收到
  • 定期测试通知渠道的可用性
  • 根据团队工作习惯选择合适的通知方式

🎯总结

通知方式配置要点：

  • ✅ 通知方式在告警规则中配置，不是独立配置项
  • ✅ 每个告警规则可以配置多种通知方式
  • ✅ 统计卡片显示所有规则的通知配置状态
  • ✅ 支持界面提示、邮件、短信、钉钉四种通知方式
  • ✅ 可以根据告警等级配置不同的通知策略
