# 新增规则向导默认值修复完成报告

## 🚨 用户需求

用户反馈新增规则向导需要修复以下默认值选择问题：

1. **温度异常** → 第二步默认选择"温度传感器" → 设备默认选择第一个设备
2. **电气异常** → 第二步默认选择"断路器" → 设备默认选择第一个设备  
3. **设备异常** → 第二步默认选择"服务器" → 设备默认选择第一个设备

### 问题描述
- 用户在第一步选择告警类型后，进入第二步时硬件类型和设备选择没有自动设置默认值
- 用户需要手动选择硬件类型和设备，体验不够友好
- 缺乏智能化的默认值设置逻辑

## ✅ 修复方案

### 1. 智能默认值设置逻辑

添加了根据告警类型自动设置硬件类型和设备默认值的功能：

#### 告警类型映射关系
```javascript
const setDefaultHardwareByAlarmType = () => {
  const alarmType = newRuleForm.value.type
  
  // 根据告警类型设置默认硬件类型
  switch (alarmType) {
    case '温度异常':
      newRuleForm.value.hardwareType = 'temperature'  // 温度传感器
      break
    case '电气异常':
      newRuleForm.value.hardwareType = 'breaker'      // 断路器
      break
    case '设备异常':
      newRuleForm.value.hardwareType = 'server'       // 服务器
      break
    default:
      // 网络异常或其他类型，默认选择服务器
      newRuleForm.value.hardwareType = 'server'
      break
  }
  
  // 设置默认设备（第一个设备）
  setDefaultDevice()
}
```

#### 默认设备选择逻辑
```javascript
const setDefaultDevice = () => {
  const hardwareOptions = getHardwareOptions()
  
  if (hardwareOptions.length > 0) {
    const firstDevice = hardwareOptions[0]
    newRuleForm.value.hardwareId = firstDevice.id
    newRuleForm.value.hardwareName = firstDevice.name
    console.log('设置默认设备:', firstDevice)
  }
}
```

### 2. 向导步骤导航优化

修改了 `nextStep` 函数，在从第一步进入第二步时自动设置默认值：

```javascript
const nextStep = () => {
  if (currentStep.value < 3) {
    currentStep.value++
    
    // 从第一步进入第二步时，根据告警类型设置默认硬件类型和设备
    if (currentStep.value === 1) {
      setDefaultHardwareByAlarmType()
    }
  }
}
```

### 3. 硬件类型变更处理优化

优化了 `onHardwareTypeChange` 函数，在硬件类型变更时也自动设置默认设备：

```javascript
const onHardwareTypeChange = () => {
  console.log('硬件类型变更:', newRuleForm.value.hardwareType)
  
  // 清空之前的选择
  newRuleForm.value.hardwareId = ''
  newRuleForm.value.hardwareName = ''
  newRuleForm.value.operator = ''
  newRuleForm.value.value = ''
  
  // 设置默认设备（第一个设备）
  setTimeout(() => {
    setDefaultDevice()
  }, 100) // 延迟确保硬件数据已加载
}
```

## 🎯 修复要点

### 1. 智能映射关系
- **温度异常** ↔ **温度传感器** (temperature)
- **电气异常** ↔ **断路器** (breaker)  
- **设备异常** ↔ **服务器** (server)
- **网络异常** ↔ **服务器** (server) - 默认选择
