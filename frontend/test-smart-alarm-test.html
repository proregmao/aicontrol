📋 具体测试示例

规则：前进风口 温度 > 25°C 通过钉钉告警

智能测试过程：
1. 硬件连接检查 → 前进风口设备连接正常 ✅
2. 当前数据获取 → 前进风口温度当前值：23.5°C ✅
3. 触发条件检查 → 23.5°C ≤ 25°C，条件未满足 ℹ️
4. 通知渠道测试 → 钉钉消息发送成功 ✅

结论：当前温度正常，未达到告警阈值，规则不会触发
建议：如需测试告警功能，可临时调整阈值或等待温度上升
