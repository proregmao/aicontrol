❌问题概述

用户反映告警规则编辑功能存在严重的条件解析问题：

  1. 复杂条件解析失败 - "断路器1 电压 < 200V" 只解析出数值 "1" 而不是 "200"
  2. 硬件名称提取错误 - "ubuntu 状态 = offline" 无法正确提取硬件名称
  3. 硬件选择不匹配 - 解析出的硬件名称无法匹配到具体的硬件设备
  4. 条件预览显示错误 - 显示 "断路器设备 电压 < 1V" 而不是正确的条件

🔧修复方案

1. 改进条件解析正则表达式

// 修复前：简单匹配第一个数字 const match = condition.match(/(\d+)V?/) // 匹配到 "1" // 修复后：精确匹配操作符后的数值 const match = condition.match(/电压\s*<\s*(\d+)V?/) // 匹配到 "200"

2. 增强硬件名称提取逻辑

// 修复前：无法处理复杂格式 if (condition.includes('电压')) { currentRule.value.hardwareName = '断路器设备' // 固定值 } // 修复后：动态提取硬件名称 const hardwareMatch = condition.match(/^([^电]+)电压/) if (hardwareMatch) { parsedHardwareName = hardwareMatch[1].trim() // 提取 "断路器1" currentRule.value.hardwareName = parsedHardwareName }

3. 新增状态条件解析支持

// 新增：支持 "硬件名 状态 = 值" 格式 else if (condition.includes('状态')) { currentRule.value.hardwareType = 'server' // 提取硬件名称，如 "ubuntu 状态 = offline" 中的 "ubuntu" const hardwareMatch = condition.match(/^([^状]+)状态/) if (hardwareMatch) { parsedHardwareName = hardwareMatch[1].trim() currentRule.value.hardwareName = parsedHardwareName } if (condition.includes('= offline')) { currentRule.value.operator = 'status_eq' currentRule.value.value = 'offline' } }

4. 优化硬件匹配策略

// 修复前：只有模糊匹配 const matchedServer = servers.value.find(server => server.name && rule.condition.includes(server.name) ) // 修复后：精确匹配 + 模糊匹配 // 1. 优先使用解析出的硬件名称进行精确匹配 if (currentRule.value.hardwareName && currentRule.value.hardwareName !== '服务器设备') { matchedServer = servers.value.find(server => server.name === currentRule.value.hardwareName ) } // 2. 如果精确匹配失败，使用条件字符串进行模糊匹配 if (!matchedServer) { matchedServer = servers.value.find(server => server.name && rule.condition.includes(server.name) ) }
