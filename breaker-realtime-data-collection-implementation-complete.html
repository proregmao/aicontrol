🚀 断路器实时数据采集系统实现完成

基于RS485-ETH-M04网关的LX47LE-125智能断路器实时数据采集与存储系统

实现总结

✅ 系统实现完成！

已成功实现基于您需求的断路器实时数据采集系统，支持分时读取策略、优先级控制操作、数据库缓存和前端实时显示。

🎯 核心特性

  • 分时读取策略：参数读取 → 锁定状态 → 分合闸状态，避免寄存器冲突
  • 优先级控制：控制操作（锁定/分合闸）具有最高优先级，会中断数据采集
  • 连接管理：每次读取后关闭连接暂停1秒，确保设备稳定
  • 数据缓存：优先从缓存获取数据，通信失败时显示上次有效数据
  • 配置化管理：采集间隔、数据保留期等通过环境变量配置

系统架构

🔄 数据采集流程

1
参数读取周期：读取电压、电流、功率、频率、漏电流、温度等电气参数
2
关闭连接暂停1秒：确保设备连接稳定
3
锁定状态周期：读取远程锁定状态（40013寄存器）
4
关闭连接暂停1秒：避免寄存器冲突
5
分合闸状态周期：读取断路器开关状态（30001寄存器）
6
数据存储：保存到数据库并更新缓存

⚡ 控制操作流程（高优先级）

1
暂停数据采集：避免与控制操作冲突
2
关闭连接暂停1秒：确保连接清洁
3
执行控制操作：合闸/分闸/锁定/解锁
4
恢复数据采集：继续正常采集周期

🗄️ 数据库表结构

-- 实时数据表 CREATE TABLE breaker_realtime_data ( id SERIAL PRIMARY KEY, breaker_id INTEGER NOT NULL, voltage DECIMAL(8,2), -- 电压(V) current DECIMAL(8,3), -- 电流(A) power DECIMAL(10,3), -- 有功功率(kW) power_factor DECIMAL(5,3), -- 功率因数 frequency DECIMAL(6,2), -- 频率(Hz) leakage_current DECIMAL(8,3), -- 漏电流(mA) temperature DECIMAL(6,2), -- 温度(°C) status VARCHAR(10), -- 状态: on/off is_locked BOOLEAN, -- 是否锁定 is_local_locked BOOLEAN, -- 是否本地锁定 data_source VARCHAR(20), -- 数据来源: modbus/cache/default is_valid BOOLEAN DEFAULT true, -- 数据是否有效 error_message TEXT, -- 错误信息 created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ); -- 采集状态表 CREATE TABLE breaker_data_collection_status ( id SERIAL PRIMARY KEY, breaker_id INTEGER NOT NULL UNIQUE, current_cycle INTEGER, -- 当前采集周期 last_collection_at TIMESTAMP, -- 最后采集时间 next_collection_at TIMESTAMP, -- 下次采集时间 is_collecting BOOLEAN, -- 是否正在采集 collection_errors INTEGER, -- 连续错误次数 total_collections BIGINT, -- 总采集次数 successful_collections BIGINT, -- 成功采集次数 created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ); -- 控制操作记录表 CREATE TABLE breaker_control_operations ( id SERIAL PRIMARY KEY, breaker_id INTEGER NOT NULL, operation VARCHAR(20), -- close/open/lock/unlock status VARCHAR(20), -- pending/executing/completed/failed priority INTEGER DEFAULT 1, -- 优先级 requested_by VARCHAR(100), -- 请求用户 started_at TIMESTAMP, completed_at TIMESTAMP, error_message TEXT, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

🔧 核心服务组件

  • BreakerDataCollector：数据采集服务，实现分时读取和优先级控制
  • ModbusService：MODBUS通信服务，支持真实数据读取和安全模式
  • BreakerService：断路器业务服务，提供统一的数据访问接口

API接口

📡 新增API端点

GET /api/v1/breakers/{id}/latest-data # 获取断路器最新实时数据 # 优先从缓存获取，缓存无效时从数据库获取 # 通信失败时显示上次有效数据 POST /api/v1/breakers/{id}/control # 提交控制操作（高优先级） # 支持：close（合闸）、open（分闸）、lock（锁定）、unlock（解锁） GET /api/v1/breakers/{id}/collection-status # 获取数据采集状态 # 显示当前采集周期、错误次数、成功率等信息

使用说明

⚙️ 监控和调试

  • 查看采集状态：通过API获取每个断路器的采集状态
  • 检查日志：系统提供详细的采集和控制操作日志
  • 数据验证：检查数据库中的实时数据记录
  • 错误处理：通信失败时会显示具体错误信息
💡 重要提醒

1. 寄存器相斥性：系统严格按照分时读取策略，避免同时读取冲突寄存器
2. 控制操作优先级：锁定和分合闸操作具有最高优先级，会暂停数据采集
3. 连接管理：每次操作后都会关闭连接并暂停1秒，确保设备稳定
4. 数据可靠性：通信失败时显示上次有效数据，不会显示错误状态
